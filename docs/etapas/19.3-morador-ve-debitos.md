# Etapa 19.3 — O morador vê os débitos e é avisado deles

- **Branch:** `feature/morador-ve-debitos` (criada a partir de `desenvolvimento`)
- **Concluída em:** 26/11/2026

## Objetivo

Uma unidade pode ter várias pessoas vinculadas, cada uma com o próprio login. Até aqui, só o **proprietário** e o
**inquilino** viam os débitos da unidade e recebiam os avisos de cobrança. Agora o **morador** também vê e é avisado.

## Decisões (tomadas com você)

| Tema | Decisão |
|---|---|
| Quantas pessoas por unidade | Várias, cada uma com o próprio login (não há limite de um por unidade) |
| Quem vê "Meus débitos" (boleto e Pix) | Proprietário, inquilino e **morador**. O dependente (ex.: filho menor), não |
| Quem recebe os avisos de cobrança | Os mesmos que veem os débitos |
| Quem responde pela cobrança (nome e CPF no boleto) | Sem mudança: proprietário ou inquilino |

| Vínculo | Vê os débitos | Recebe os avisos de cobrança | Reserva espaços |
|---|---|---|---|
| Proprietário | Sim | Sim | Sim |
| Inquilino | Sim | Sim | Sim |
| Morador | **Sim** | **Sim** | Sim |
| Dependente | Não | Não | Não |

## O que mudou
- `CadastroParaCobranca.unidadesComDebitosVisiveis` (antes `unidadesDoPagador`): inclui o morador. Vale para
  "Meus débitos" (`GET /api/eu/cobrancas`) e para o boleto e o Pix (`GET /api/eu/cobrancas/{id}/pagamento`).
- `DestinatariosDeNotificacoes.quemAcompanhaOsDebitos` (antes `pagadoresDaUnidade`): os mesmos vínculos. Vale para
  "Nova cobrança", "Vence em 3 dias" e "Pagamento confirmado", no app, por e-mail e push.
- Ver e ser avisado usam a mesma regra, para não saírem de sincronia.

## Como verificar

```bash
./mvnw test                  # FinanceiroTests: o morador vê, o dependente não; NotificacoesTests: o morador é avisado, o dependente não
cd frontend && npm test      # frontend: 52 testes
```
